# Catalogue

The public catalogue lists **only verified public-domain or CC0 scores**, each with a provenance
record (spec §2, §9). Everything a user imports goes to their private library instead and never
appears here.

## Layout

```text
catalogue/
  index.json                 generated by tools/pipeline/build_index.py — do not edit
  schema/provenance.schema.json
  pieces/<slug>/
    provenance.json          required, see the schema
    score.musicxml           the score (or score.mxl)
    arrangement.txt          optional: source for arrangements written with arrange.py
```

## Adding a piece

1. Check the music is free in the EU: every composer (and lyricist, if there are lyrics) died in
   **1955 or earlier** for a 2026 release, or the tune is traditional.
2. Use a transcription that is the transcriber's own work under CC0, public domain or CC BY —
   never a scan or copy of a publisher's edition (scholarly and first editions have their own
   protection in Germany, §§ 70/71 UrhG). PDMX entries come only from its `no_license_conflict`
   subset.
3. Create `pieces/<slug>/` with the score and a `provenance.json` (copy an existing one).
   Leave `verified: false` and `reviewed_by: null`.
4. Run the checks and rebuild the index:

   ```sh
   python3 tools/pipeline/build_index.py
   python3 tools/pipeline/validate_catalogue.py
   ```

5. Open a pull request with the **catalogue** template. CI rejects missing fields and composers
   inside the EU term.

### Writing a simple arrangement

For beginner arrangements of public-domain tunes, write `arrangement.txt` in the compact notation
described at the top of [`tools/pipeline/arrange.py`](../tools/pipeline/arrange.py) and render it:

```sh
python3 tools/pipeline/arrange.py catalogue/pieces/<slug>/arrangement.txt > catalogue/pieces/<slug>/score.musicxml
```

Your arrangement is released under CC0 1.0.

## Reviewing a piece (about 10 minutes)

A human reviewer listens to the piece in the app, checks the notes against a public-domain
source, checks the hand split, title and composer, then sets `verified: true` and
`reviewed_by: "<your GitHub handle>"`. Only verified pieces appear in production builds.

## Licences

Catalogue metadata (provenance records, index) and the pipeline scripts are
[CC0 1.0](LICENSE). Each score keeps its own source licence, recorded in its provenance file.

## Takedown

If you believe a piece is still protected, open an issue or use the contact in the Impressum.
Pieces are removed within 48 hours while the claim is checked.
