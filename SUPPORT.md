# Getting help

OpenTiles is maintained by volunteers. Here is where to go for what.

| I want to…                                | Go to                                                                                                          |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Learn how to use the app                  | The [user guide](docs/user-guide.md) and the [FAQ](docs/faq.md)                                                |
| Ask a question                            | [Discussions → Q&A](https://github.com/KunalGehlot/OpenTiles/discussions/new?category=q-a)                     |
| Suggest an idea or talk about the roadmap | [Discussions → Ideas](https://github.com/KunalGehlot/OpenTiles/discussions/new?category=ideas)                 |
| Show what I made or how I practise        | [Discussions → Show and tell](https://github.com/KunalGehlot/OpenTiles/discussions/new?category=show-and-tell) |
| Report a bug or a microphone problem      | [Open an issue](https://github.com/KunalGehlot/OpenTiles/issues/new/choose)                                    |
| Propose a catalogue piece                 | [Catalogue form](https://github.com/KunalGehlot/OpenTiles/issues/new?template=catalogue-piece.yml)             |
| Report a security problem                 | Privately; see [SECURITY.md](SECURITY.md)                                                                      |
| Report a conduct problem                  | Privately; see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)                                                        |
| Contribute                                | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                             |

When you report a problem, tell us your device, operating system, browser and how you play (MIDI
keyboard, microphone or on-screen keys). Please **do not attach copyrighted scores, MIDI files or
recordings**; use a piece from the public-domain catalogue to show the problem.
